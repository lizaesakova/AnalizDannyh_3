# Задание 3 — Мини-продукт с LLM-аналитикой

## Описание задания

**Задание 3** по курсу "Аналитика данных"

**Цель:** собрать работающий продукт, который решает аналитическую задачу с помощью ИИ-агента.

### Agent Analiz Dannih — это интерактивное веб-приложение на Streamlit, которое позволяет:
- Загружать файлы данных в форматах CSV, XLS, XLSX
- Отправлять запросы к AI-агенту на базе GigaChat API
- Получать структурированный анализ: метрики, тренды, аномалии, рекомендации
- Работать с локальными данными без отправки за пределы вашего окружения (кроме промпта в API)
- Приложение автоматически готовит контекст данных для нейросети, ограничивая объём передаваемой информации для экономии токенов.

##  Инструкция по запуску

### Требования
- Python 3.9 или выше
- Pandas
- API ключ (GigaChat)


### Шаг 1: Настройка API ключа

по инструкции с сайта
https://arturgolubev.ru/knowledge/course35/lesson223/
я получила себе ключ для LLM Гигачат и сохранила его в файл .env:
GIGACHAT_API_KEY=

### Шаг 2: Установка зависимостей
Я перехожу в комнадной строке к папке проекта и загружаю необходимые зависимости через

pip install -r requirements.txt

### Шаг 3: запуск

я запустила в папке проекта файл app11.py с основным кодом через командную строку: streamlit run app11.py
