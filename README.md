## Как работает код:

 - Запуск → main.py загружает DataFrame → создаёт DataAnalysisAgent (из agent_loop.py), передавая данные и API-ключ.
 - Запрос к LLM → Агент формирует промпт с контекстом → отправляет запрос в GigaChat API.
 - Парсинг ответа → Если LLM возвращает JSON-вызов инструмента, agent_loop.py извлекает его методом _parse_tool_call_from_text().
 - Выполнение инструмента → Агент вызывает self.tools.execute() (из agent_tools.py).
 - Безопасное исполнение → agent_tools.py запускает код в песочнице (sanitize_code + safe_execution_environment + таймаут) → возвращает структурированный результат.
 - Возврат в цикл → Результат добавляется в историю диалога в agent_loop.py → цикл повторяется (шаг 2), пока LLM не сгенерирует финальный текстовый ответ без вызова инструментов.
 - Вывод → agent_loop.py возвращает финальный ответ, логи и метрики в main.py → Streamlit отображает их в интерфейсе.

#### main.py
Streamlit-приложение: принимает файл и вопрос, строит графики, запускает агента и выводит итог пользователю.

### agent_loop.py
Класс DataAnalysisAgent: управляет циклом диалога с GigaChat, кэширует токены, парсит ответы LLM, решает когда вызывать инструменты и контролирует лимит итераций.
 - _get_access_token() - получение и кэширование токена (@lru_cache + TTL)
 - _parse_tool_call_from_text() - парсинг с вызовом инструмента из текста LLM
 - _build_system_prompt() - генерация системного промпта со схемой инструментов и правилами
 - _call_llm() - HTTP-запрос к GigaChat API с обработкой ответа

#### agent_tools.py
Класс ToolRegistry и утилиты безопасности: выполняет Python/pandas-код от LLM в изолированном окружении с таймаутами, фильтрацией опасных операций и ограничением вывода. 
#### Доступные инструменты ToolRegistry
 - execute_python - выполнение pandas/Python-кода в песочнице
 - get_column_info - информация о колонке
 - filter_data - фильтрация DataFrame по условию
