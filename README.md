# Задание 3 — Мини-продукт с LLM-аналитикой

## Описание задания

**Задание 3** по курсу "Аналитика данных"

**Цель:** собрать работающий продукт, который решает аналитическую задачу с помощью ИИ-агента.

### Agent Analiz Dannih — это интерактивное веб-приложение на Streamlit, которое позволяет:
- Загружать файлы данных в форматах CSV, XLS, XLSX
- Отправлять запросы к AI-агенту на базе GigaChat API
- Получать структурированный анализ: метрики, тренды, аномалии, рекомендации
- Работать с локальными данными без отправки за пределы вашего окружения (кроме промпта в API)
- Приложение автоматически готовит контекст данных для нейросети, ограничивая объём передаваемой информации для экономии токенов.

## Как работает код:
 - Загружаются переменные окружения из .env (API-ключ GigaChat)
 - Настраивается конфигурация страницы Streamlit
 - Функция get_gigachat_access_token() получает токен
 - Токен кэшируется на 55 минут (@st.cache_resource)
 - Пользователь загружает CSV/Excel-файл и данные считываются
#### Визуализация
 - Автоматически определяются числовые колонки
 - Доступные типы графиков: Гистограмма распределения, Корреляционная матрица, Scatter plog,Box plot
 - Для больших датасетов (>10 000 строк) применяется сэмплирование
#### Подготовка контекста для ИИ
 - Функция prepare_dataframe_for_prompt() формирует компактное описание данных: Метаинформация (форма, колонки, типы), статистика по числовым признакам, пропущенные значения, первые 50 строк как пример
#### Запрос к GigaChat
 - Формируется промпт с ролью «профессиональный аналитик данных»
 - Отправляется POST-запрос на GIGACHAT_CHAT_URL с:
 - Системным сообщением (ограничение роли)
 - Пользовательским запросом + контекст данных
 - Параметрами: temperature=0.3, max_tokens=4000
 - Ответ парсится и выводится в интерфейсе
#### Кэширование и оптимизация
 - @lru_cache для API-ключа
 - @st.cache_resource(ttl=3300) для токена доступа
 - Как работает кэширование:
    - Первый вызов: Функция выполняется, токен запрашивается у API, результат сохраняется в кэше
    - Повторные вызовы (в течение 55 минут): Возвращается закэшированный токен без обращения к API
    - После 55 минут: Запрашивается новый токен
 - Сэмплирование данных для быстрой отрисовки графиков
